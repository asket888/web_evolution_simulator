# Web evolution simulator

An aquarium where herbivores and predators learn to survive: every creature is controlled by a tiny neural network,
and the networks are improved by a genetic algorithm.

This is the web and Android version of the [Python evolution simulator](https://github.com/asket888/python_evolution_simulator),
rewritten in TypeScript. The Python version is the reference for the simulation rules and balance.

**Open it in the browser: https://asket888.github.io/web_evolution_simulator/**

> Work in progress: the simulation core is ported from Python and checked against it; the page shows a live aquarium
> with basic controls. Next: parameters panel, fun UI, Android app.

## What is on the page

- the live aquarium: green – herbivores (with the tail of the last move), blue – food, red – predators,
  yellow – dead herbivores (bodies), gray – dead predators
- Play / Pause, speed (¼× … 30× ticks per frame), **+10 generations** fast-forward
- **Seed** + **New world**: the same seed gives the same run
- stats of the last finished generation and a chart: herbivores / predators survived and herbivores killed by generation

The rules are the same as in the Python version: see its README for how herbivores, predators and evolution work.

## Stack

- [Vite](https://vite.dev) + TypeScript + React – the app
- Canvas 2D – the aquarium
- [Vitest](https://vitest.dev) – tests
- [Capacitor](https://capacitorjs.com) – Android app (Android 7+, built for Android 16 / API 36)
- GitHub Actions – tests, publishes the web app to GitHub Pages and builds the Android APK in the cloud, no Android Studio needed

## Run locally

Requires Node.js 22+.

```bash
npm install
npm run dev      # dev server with hot reload
npm test         # tests
npm run lint     # linter
npm run build    # production build into dist/
```

Balance check without the browser (Node.js 23+ runs the TypeScript core directly) – the same metrics as the
Python experiments, by 10-generation blocks:

```bash
node scripts/balance.ts            # 5 seeds, default settings
node scripts/balance.ts --20       # 20 seeds
node scripts/balance.ts --no-pred  # herbivores only
```

## Android APK

Every push to `main` builds a debug APK in GitHub Actions:
open the **Actions** tab → the latest **Build** run → download the `evolution-simulator-debug-apk` artifact,
unzip it and install `app-debug.apk` on the phone (Android asks once to allow installing apps from this source).

Local build without Android Studio (needs JDK 21 and Android SDK command-line tools):

```bash
npm run build
npx cap sync android
cd android && ./gradlew assembleDebug
```

## Project structure

| Path | What is there |
|---|---|
| `src/sim/` | simulation core (pure TypeScript, no UI): world, creatures, brain, evolution, settings |
| `src/ui/` | aquarium drawing and the chart |
| `scripts/balance.ts` | headless balance check |
| `src/App.tsx` | the app UI |
| `android/` | Android project generated by Capacitor |
| `.github/workflows/build.yml` | cloud build: lint, tests, web build, GitHub Pages, Android APK |
